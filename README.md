# Markdown Site Template
Simple template for creating a markdown site.

Useful for making documentation and easy to modify.

Feel free to fork this, don't forget to remove CNAME.

## How to Use
To add text to the main page, modify index.md.

To add other pages, for example if you are adding a pane called "help", duplicate index.md as "help.md" and change the permalink to /help.html.

To change your license or email, modify lines 147-160 in ''_layouts/default.html''
